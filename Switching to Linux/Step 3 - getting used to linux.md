
the hardest part about linux in my opinion so far is moving around and finding out how things work, so for this I decided to learn terminal navigation and utilization through customization (a lot of "ation" lol)

 ### Configs I decided to add:
 
  - ***nvim*** - just a better file editor imo, i like how much cleaner it looks personally
  - ***eza*** - i prefer this over ls as I think it looks nicer
  - ***bat*** - changed cat to bat in my .bashrc cause I like the formatting more
  - ***fast fetch*** - probbably the coolest part to my terminal, it looks really nice and learning how to use it was a good experience
  - ***themes*** - I think i got cattpuccino or something, looks nice
  - ***widgets*** - downloaded cava for my sound based widgets which looks really nice


 #### basic necessary commands
 
 > cd, ls, pwd, eza , cat, bat, nano, nvim

First few commands I learned, I already knew about cd, ls, nano, and pwd but since I was on windows there was no need to use nano or cat, but after switching these became essential. Then finding replacements that look a lot nicer like eza replacing ls, bat replacing cat, and nvim replacing nano.  
 
 #### Slightly more advanced and useful commands
 
>  touch (file), cp (file 1) to (file 2), mv (file1 to file2), rm (file)  

 I diddnt use these much since I relied on dolphin a bit but knowing these is really good to know. I still need to figue out how to use the -options more effectivley
 
  #### help stuff
  
> man , tldr, search , find

These where **such** a big help omg. man was nice but it got annoying as it showed too much sometimes so tldr was a nice replacement to get. And having find saved me so often, any time i needed to find a specific config file or something like that it was so nice to be able to be able to do


  #### Package manager (dnf in my case)

> install, remove, upgrade , search, info, list, autoremove, clean all, (repoquery --requires), history, distro-sync , check-upgrade

Very important imo to figure out, things like inststall and remove are obviously important but things like search and info are super convinient when looking for things you may need. Then the things like check-upgrade, autoremove, clean all, and distro-sync are nice to use once in a while to remove random things you may not need and too keep everything up to date
